# Indicaciones para Agente IA de Replit - Sistema de Login

## CONTEXTO DEL PROYECTO

Tengo una plataforma educativa de IA que replica la funcionalidad de rundown.ai con la siguiente estructura:

### Flujo de Usuario:
1. **Landing Page** → Usuario llega al sitio web principal
2. **AI University** → Sección educativa con opciones de suscripción
3. **Checkout** → Proceso de pago (prueba gratis, mensual, anual)
4. **App Dashboard** → Plataforma de estudio (requiere autenticación)

### Estados de la Aplicación:
- **Sin Login**: Usuarios ven contenido limitado/promocional
- **Con Login**: Usuarios acceden a contenido completo y personalizado

## COMPORTAMIENTO ESPERADO

1. Usuario completa checkout → Cuenta se activa automáticamente

4. Sesión persiste entre reloads de página
